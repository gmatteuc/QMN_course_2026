================================================================================
  Quantitative Methods in Neuroscience (QMN) - Setup Guide
  Master in Neuroscience, University of Geneva - Academic year 2026-27
================================================================================

This guide takes you from a blank laptop to a working setup for the QMN
practicals: conda + a "qmn" Python environment + the course notebooks
running in VS Code. You only need to do this once.

The TAs will walk through these steps with you in the Week 1 practical.
If you have never installed Python before, read top to bottom and run
the commands exactly as written.

There is also an illustrated version of steps 1 to 3, with screenshots:
QMN_setup_guide_students.pdf, in this same folder.


--------------------------------------------------------------------------------
  1.  INSTALL CONDA  (skip if you already have Anaconda or Miniconda)
--------------------------------------------------------------------------------

We recommend Miniconda, the minimal conda installer: it gives you conda
and a Python, and nothing else. Download the installer for your OS and
run it with the options it recommends:

    https://www.anaconda.com/docs/getting-started/miniconda/install

On Windows, leave the PATH option as the installer sets it: you will work
from the Anaconda Prompt, which finds conda on its own. Open a terminal
(on Windows the "Anaconda Prompt (miniconda3)", from the Start menu) and
verify:

    conda --version

You should see something like "conda 24.9.0". If you get "command not
found", close the terminal, reopen it, and try again.

Also install VS Code (https://code.visualstudio.com) and, from its
Extensions panel, these official Microsoft extensions:

    Python      (installs Pylance and the Python Debugger with it)
    Jupyter     (runs notebooks inside VS Code)


--------------------------------------------------------------------------------
  2.  GET THE COURSE MATERIAL
--------------------------------------------------------------------------------

Download (or git-clone) the course folder shared on Moodle and place it
somewhere convenient on your computer, e.g.:

    Windows        ->  %USERPROFILE%\QMN_course
    macOS / Linux  ->  ~/QMN_course

%USERPROFILE% and ~ both mean your own user folder, so you never have to
type your user name. Somewhere else works too, as long as you use your own
path below.

Open a terminal and "cd" into that folder:

    Anaconda Prompt:        cd %USERPROFILE%\QMN_course
    macOS / Linux:          cd ~/QMN_course

Run "dir" (Windows) or "ls" (macOS / Linux) and check that you see at
least:

    environment.yml
    README.md
    SETUP_INSTRUCTIONS.txt
    notebooks/


--------------------------------------------------------------------------------
  3.  CREATE THE "qmn" ENVIRONMENT
--------------------------------------------------------------------------------

From the project root (the folder that contains environment.yml), run:

    conda env create -f environment.yml

This installs Python and all required libraries; it takes 5-15 minutes
depending on your connection. Grab a coffee. Then activate it:

    conda activate qmn

You should now see "(qmn)" at the start of your terminal prompt. Every
Python / pip / jupyter command from this point on uses the qmn environment.

If conda says that qmn already exists, you have set it up before. Do not
remove it: update the one you have instead.

    conda env update -n qmn -f environment.yml --prune

Nothing needs to be registered: the Jupyter extension in VS Code finds conda
environments by itself, since ipykernel is part of the environment. Only if
qmn never shows up in the kernel list, or if you start JupyterLab from
outside the environment, run this once with qmn active:

    python -m ipykernel install --user --name qmn


--------------------------------------------------------------------------------
  4.  OPEN A NOTEBOOK AND CHECK YOUR SETUP
--------------------------------------------------------------------------------

In VS Code (recommended):

    code .

The fastest check, with the qmn environment active. From the course folder:

    python notebooks/src/check_env.py

(or "python src/check_env.py" if you are already inside notebooks/)

It prints one line per package with the version you actually have, one line
per dataset, and tells you what to do if something is missing.

The same check from inside any notebook, which also verifies that the kernel
you selected is the right one:

    from src.check_env import check_environment
    check_environment()

Then open the first notebook of the course from the notebooks/ folder,
01_programming_fundamentals.ipynb, click "Select Kernel" (top-right)
and choose the qmn environment, listed under "Python Environments". Run the
first two code cells (Shift+Enter):
if they print package versions and the first rows of the dataset, your
setup works.


--------------------------------------------------------------------------------
  5.  DAILY WORKFLOW
--------------------------------------------------------------------------------

Every time you come back to work on the course:

    cd ~/QMN_course          (Windows: cd %USERPROFILE%\QMN_course)
    conda activate qmn
    code .

You do NOT need to repeat step 3 - the environment is already there.


--------------------------------------------------------------------------------
  6.  MAINTENANCE & TROUBLESHOOTING
--------------------------------------------------------------------------------

  * To pick up a new package added during the semester:
        conda activate qmn
        conda env update -f environment.yml --prune

  * To start over from scratch (if something is broken):
        conda deactivate
        conda env remove -n qmn
        conda env create -f environment.yml

  * To list existing environments on your machine:
        conda info --envs
