================================================================================
  Quantitative Methods in Neuroscience (QMN) - Setup Guide
  Master in Neuroscience, University of Geneva - Academic year 2026-27
================================================================================

This guide takes you from a blank laptop to a working setup for the QMN
practicals: conda + a "qmn" Python environment + the course notebooks
running in VS Code. You only need to do this once.

The TAs will walk through these steps with you in the Week 1 practical.
If you have never installed Python before, read top to bottom and run
the commands exactly as written.


--------------------------------------------------------------------------------
  1.  INSTALL CONDA  (skip if you already have Anaconda or Miniconda)
--------------------------------------------------------------------------------

We recommend Miniforge (minimal conda + open conda-forge channel, no
Anaconda account required). Download the installer for your OS and run
it with the default options:

    https://conda-forge.org/download/

On Windows, accept "Add Miniforge to my PATH" if asked. Then open a new
terminal (on Windows: the "Miniforge Prompt", or any shell with conda on
PATH) and verify:

    conda --version

You should see something like "conda 24.9.0". If you get "command not
found", close the terminal, reopen it, and try again.

Also recommended: install VS Code (https://code.visualstudio.com) plus
its official "Python" and "Jupyter" extensions.


--------------------------------------------------------------------------------
  2.  GET THE COURSE MATERIAL
--------------------------------------------------------------------------------

Download (or git-clone) the course folder shared on Moodle and place it
somewhere convenient on your computer, e.g.:

    Windows  ->  C:\Users\<your-name>\Documents\QMN_course
    macOS    ->  /Users/<your-name>/Documents/QMN_course
    Linux    ->  /home/<your-name>/Documents/QMN_course

Open a terminal and "cd" into that folder:

    Windows (PowerShell):   cd $HOME\Documents\QMN_course
    macOS / Linux:          cd ~/Documents/QMN_course

Run "dir" (Windows) or "ls" (macOS / Linux) and check that you see at
least:

    environment.yml
    README.md
    SETUP_INSTRUCTIONS.txt
    notebooks/


--------------------------------------------------------------------------------
  3.  CREATE THE "qmn" ENVIRONMENT
--------------------------------------------------------------------------------

From the project root (the folder that contains environment.yml), run:

    conda env create -f environment.yml

This installs Python and all required libraries; it takes 5-15 minutes
depending on your connection. Grab a coffee. Then activate it:

    conda activate qmn

You should now see "(qmn)" at the start of your terminal prompt. Every
Python / pip / jupyter command from this point on uses the qmn environment.

Register qmn as a Jupyter kernel so VS Code (and JupyterLab) can find it:

    python -m ipykernel install --user --name qmn --display-name "Python (qmn)"


--------------------------------------------------------------------------------
  4.  OPEN A NOTEBOOK AND CHECK YOUR SETUP
--------------------------------------------------------------------------------

In VS Code (recommended):

    code .

The fastest check, from the notebooks/ folder with the environment active:

    python src/check_env.py

It prints one line per package with the version you actually have, one line
per dataset, and tells you what to do if something is missing.

The same check from inside any notebook, which also verifies that the kernel
you selected is the right one:

    from src.check_env import check_environment
    check_environment()

Then open any notebook from the notebooks/ folder, for example
notebooks/02_math_refresher_TA.ipynb, click "Select Kernel" (top-right)
and choose "Python (qmn)". Run the first two code cells (Shift+Enter):
if they print package versions and the first rows of the dataset, your
setup works.

Alternative - JupyterLab:

    jupyter lab

then open the notebook from the file tree and pick "Python (qmn)" from
the Kernel menu.


--------------------------------------------------------------------------------
  5.  DAILY WORKFLOW
--------------------------------------------------------------------------------

Every time you come back to work on the course:

    cd ~/Documents/QMN_course      # or wherever you put it
    conda activate qmn
    code .                         # or:  jupyter lab

You do NOT need to repeat step 3 - the environment is already there.


--------------------------------------------------------------------------------
  6.  MAINTENANCE & TROUBLESHOOTING
--------------------------------------------------------------------------------

  * To pick up a new package added during the semester:
        conda activate qmn
        conda env update -f environment.yml --prune

  * To start over from scratch (if something is broken):
        conda deactivate
        conda env remove -n qmn
        conda env create -f environment.yml

  * To list existing environments on your machine:
        conda info --envs


--------------------------------------------------------------------------------
  7.  CONTRIBUTING  (TAs / collaborators only - students can skip)
--------------------------------------------------------------------------------

Notebook outputs are deliberately KEPT in the repository while the material
is being written, so that reviewers can read a notebook's results on GitHub
without running it. Do NOT install the nbstripout filter.

If you installed it earlier (the guide used to ask for it), remove it now,
otherwise your clone will keep stripping outputs and every notebook will
show up as modified:

    nbstripout --uninstall

and check that .git/info/attributes has no line for *.ipynb.

Outputs get stripped once, at the end, by the script that generates the
student-facing repository.


--------------------------------------------------------------------------------

--------------------------------------------------------------------------------

Good luck and welcome to the course!
